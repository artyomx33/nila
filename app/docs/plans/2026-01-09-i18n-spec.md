# i18n (Internationalization) - Spec

## What We're Building
Multi-language support for NILA app with English, Spanish, and Dutch. Users can toggle between languages via a button, preference saved in cookie.

## Languages
- **English (en)** - Default
- **Spanish (es)**
- **Dutch (nl)**

## User Experience
1. Language toggle button in header/sidebar
2. Clicking cycles through: EN → ES → NL → EN (or dropdown)
3. Language preference saved in cookie (persists across sessions)
4. All UI text updates instantly on toggle (no page reload)

## Scope - IN
- UI labels, buttons, placeholders
- Navigation text
- Form field labels
- Status badges
- Error/success messages (frontend)
- Date/number formatting per locale

## Scope - OUT
- Database content (property names, guest names, notes)
- Backend/Supabase error messages
- URL-based routing (`/en/`, `/es/`)
- User-generated content

## Technical Approach
- **Library:** `next-intl` (best for Next.js App Router)
- **Translation files:** `/messages/{en,es,nl}.json`
- **No URL routing** - cookie-based only
- **Client-side toggle** - instant switch, no reload

## Acceptance Criteria
- [ ] Toggle button visible in UI (header or sidebar)
- [ ] Clicking toggle switches language instantly
- [ ] Language preference persists across browser refresh
- [ ] All 3 portals (Admin, Owner, Booker) fully translated
- [ ] All form labels, buttons, navigation in all 3 languages
- [ ] Date formatting respects locale (e.g., 01/09/2026 vs 09/01/2026)

## File Impact
- ~58 files with hardcoded strings
- New: `/messages/en.json`, `/messages/es.json`, `/messages/nl.json`
- New: Language toggle component
- Modified: All pages and components with UI text
